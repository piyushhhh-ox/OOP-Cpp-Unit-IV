DETAILED EXPLANATION — Concept 5: Count Lines, Words, and Characters

This program analyzes a text file's content by counting lines,
words, and characters using character-by-character reading.

- Header files: <cctype> provides std::isspace(), used to detect
  spaces, tabs, and newlines. <fstream> provides ifstream.

- Character-by-character reading: inputFile.get(ch) reads exactly
  one character into ch and returns the stream (convertible to
  bool), so the while loop continues until end-of-file or failure.
  This is different from Concepts 2 and 4, which read whole lines.

- Counting characters: every successful get() increments
  characterCount, regardless of what the character is.

- Counting lines: every '\n' encountered means one line has been
  completed, so lineCount is incremented.

- Counting words: insideWord acts as a state flag. Whenever a
  whitespace character is seen, insideWord is set to false. When a
  non-whitespace character appears while insideWord is false, it
  marks the start of a new word, so wordCount is incremented and
  insideWord is set to true. This correctly handles words separated
  by multiple spaces or newlines without overcounting.

- Handling the final line: files don't always end with a newline
  character. The block after the loop uses seekg(-1, std::ios::end)
  to jump to the very last character of the file and checks if it's
  '\n'. If it isn't, one more line is added to lineCount to account
  for that last, unterminated line. inputFile.clear() is required
  first because reading to end-of-file sets the stream's eof flag,
  which blocks further operations like seekg() until cleared.

Why this matters: this character-scanning technique (with a state
flag for word boundaries) is a reusable pattern for text analysis,
and it's extended directly in Concept 14 to also count vowels,
digits, and spaces.

EXPECTED CONSOLE OUTPUT (exact numbers depend on file content,
using the message.txt built up through Concepts 1–3):
Lines: 4
Words: 25
Characters: 150
